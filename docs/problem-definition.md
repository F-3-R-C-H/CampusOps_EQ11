# Definición del Problema — CampusOps

## Descripción
CampusOps es una plataforma de gestión de operaciones universitarias diseñada para optimizar procesos internos, coordinar espacios físicos y mejorar la experiencia de la comunidad académica.

## Actores principales
- **Usuario estudiante:** Consulta horarios, reserva espacios de estudio y revisa notificaciones de la universidad.
- **Usuario administrativo:** Gestiona recursos, aprueba reservas de aulas, coordina eventos y genera reportes de uso y mantenimiento.

## Flujo crítico
1. El usuario se autentica en la plataforma de CampusOps.
2. El usuario navega al módulo correspondiente según su rol.
3. Realiza la acción requerida (por ejemplo, solicitar la reserva de un espacio) y el sistema valida la disponibilidad.
4. El sistema confirma la acción, actualiza el estado en el backend y notifica a los involucrados.
